# Python Tutorial Notebook

A beginner-friendly Jupyter Notebook covering core Python programming, introductory data analysis, data visualisation, and a simple machine-learning example.

> **Repository note:** The current repository name is `ISA-Community-Website`, but the file currently stored here is a Python tutorial notebook rather than a community website implementation.

## Topics Covered

- **Python fundamentals:** variables, data types, lists, loops, list comprehensions, and functions
- **Basic calculations:** a sample BMI calculation and category function
- **Data analysis with Pandas and NumPy:** creating a small sample employee dataset, inspecting shape and data types, and generating descriptive statistics
- **Exploratory analysis:** grouping salary by department, counting employees by department, and filtering records by salary
- **Visualisation and introductory machine learning:** see the later notebook sections for the examples included there

## File

- `python-tutorial.ipynb` — the notebook containing explanations, code cells, and example outputs

## Run the Notebook

1. Clone or download this repository.
2. Open `python-tutorial.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the cells in order.

Typical local setup:

```bash
python -m pip install jupyter pandas numpy matplotlib
jupyter notebook
```

Install any additional library used by a later notebook cell if prompted.

## Learning Goals

This notebook is intended for practice with Python syntax, basic data handling, summary statistics, and the first steps toward analytical workflows. The sample employee data is illustrative and should not be interpreted as real business data.
